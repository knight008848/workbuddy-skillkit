# 技能选题市场调研与开发计划

> 本文回答一个问题：**下一个技能做什么、为什么值得做、怎么一步步做出来上架。**
> 调研时间 2026-11-03，数据来源：WorkBuddy 技能市场公开榜单、Claude Skills 生态榜单、
> skillsmp.com / skills.sh 等技能目录。本文是**选题论证**，不是现状清单（现状见 `roadmap.md`）。

---

## 一、先看清市场格局：哪里是红海，哪里是蓝海

### 1.1 WorkBuddy 技能市场的现实

- SkillHub 已有 **7 万+** 技能；全球最大的 skillsmp.com 已收录 **164 万+** 个 SKILL.md。
- 腾讯 WorkBuddy 月活已破 **2000 万**，且已开放「收入变现」：个人开发者可上架付费技能，
  支持**一次性买断 / 按月订阅**，收益可微信提现。入驻入口 open.workbuddy.cn。
- 这意味着「做技能」已经从自用/免费分享，变成了一条真实的变现通路。

### 1.2 红海区（别碰，或只做细分升级）

办公效率榜前十，下载量都是几十万级，已被官方 + 大厂 + 头部开发者占据：

| 赛道 | 代表需求 | 拥挤程度 |
|---|---|---|
| PDF 转换/处理 | 转换、合并、OCR | 🔴 极挤（累计下载 50w+） |
| Excel 数据分析 | 清洗、透视、图表 | 🔴 极挤（45w+） |
| PPT 制作/排版 | 生成幻灯片 | 🔴 极挤（40w+） |
| Word 文档处理 | 生成/编辑长文档 | 🔴 极挤（38w+） |
| 邮件 / 会议纪要 / 合同审查 / 翻译 | 通用办公 | 🔴 挤 |

**这些方向已被「官方四件套 + 中信建投蜻蜓 Skill 这类机构」占满**，个人进去等于和官方拼通用能力，
没有优势。我们的 `bilingual-subtitle` 之所以能立住，正是因为它垂直（视频字幕成片），
而不是去和「翻译」这个大词正面竞争。

### 1.3 蓝海区（机会在哪）

三份独立来源指向同一个结论：

| 信号 | 来源 | 说明 |
|---|---|---|
| 需求有、供给几乎为零 | Google Trends「Breakout」查询 | 如「task observer」「record a skill」「dataviz」，搜索暴涨但对应技能只有个位数安装 |
| 垂直行业 SOP 仍是空白 | skillsmp.com 23 大类 867 细分岗位 | 「头部开发者刚冒头，99% 行业需求还没人做」 |
| 真正付费的是「被解决的痛苦」 | Aleiah Lock 实测 17 个付费 Skill | 没人付钱买 AI，他们付钱买被解决的重复性痛苦 |

**铁律（能卖出去的选题标准）**：

> 每周高频重复 + 耗时无聊 + 流程固定 + 刚需必做

反过来说，凡是「用户每周要花 2 小时、流程其实很固定、但没人封装成技能」的活，都是机会。
**核心竞争力是「稳定可靠」，不是「偶尔出彩」。**

## 二、备选选题池（按推荐度排序）

下面每个方向都按「目标人群 / 核心流程 / 省时价值 / 竞争度 / 变现潜力」五个维度评估。

### 方向 A：垂直岗位 SOP 技能（⭐ 首选）

**逻辑**：把某个岗位「每周重复、流程固定、自己懒得写文档」的活，封装成稳定 SOP。

| 候选 | 目标人群 | 做什么 | 为什么有需求 |
|---|---|---|---|
| 教学设计生成 | 中小学/培训机构老师 | 输入年级学科主题 → 教学目标/课堂活动/分层练习 | 备课高频、模板化强、老师付费意愿高 |
| 客户周报生成 | 营销机构/乙方 | 输入周数据 → 环比/亮点/风险/行动建议 | 乙方每周必交、格式固定、直接可交付 |
| 招聘 JD + 简历筛选 | HR/猎头 | 岗位描述 → JD 生成 → 简历打分排序 | 招聘季高频、重复、易出错 |
| 会议纪要 → 行动项 | 项目经理/行政 | 纪要 → 决议/待办/责任人/截止日 | 每个会都要做、格式固定 |

**优势**：竞争少（这些岗位还没人做）、付费意愿强（直接省时）、你能用「行业判断力」建立壁垒。
**风险**：需要你真的懂那个岗位的坑，否则输出会「看起来对、实际不能用」。

### 方向 B：已有技能的全流程升级（⭐ 次选，可快速出）

**逻辑**：市场上某类技能「功能单一、评分差、安装量高」，做一个全流程完整版。

- 我们的 `bilingual-subtitle` 已经验证了这个打法：别人只做「翻译」或「转写」，
  我们做「转写→断句→翻译→烧录→验收」全链路。
- 可复用同一套流程去切相邻细分：如「会议录音 → 结构化纪要 + 行动项」、
  「外语教学视频 → 逐句精听稿」等。

**优势**：方法已验证、有现成脚本资产可复用。
**风险**：容易滑回红海（切得太宽就和通用翻译/纪要撞车）。

### 方向 C：工具类技能（⭐ 个人开发者可独立封装）

**定义**：不绑定具体岗位、而是解决「一类高频重复的操作型痛点」的技能。
特征是：输入输出格式明确、流程固定、可脚本化、无需深厚行业背景也能做扎实。

**筛选标准（20 个备选统一按此评估）**：

1. **个人可做**：不依赖平台级能力，标准库/公开 API 就能跑通；
2. **有真实高频需求**：每周会用到，而非一次性；
3. **避开红海**：不做通用 PDF/Excel/翻译/纪要这些已被官方占满的；
4. **可脚本化**：核心是「稳定可靠」的流程，不是「偶尔出彩」的创意。

#### 从 20 个里筛「值得先做」的 3 条原则

1. **高省时 + 低竞争 + 可脚本化**：优先 #1 发票整理、#4 音视频转文字、#19 竞品监控——
   这三类痛点强、供给少、流程固定，最符合「铁律」。
2. **避开已被官方占满的**：#12 可视化、#16 批量翻译、#18 格式转换——这些 WorkBuddy
   已有成熟官方/头部技能，个人进去拼不过，除非只做极细分升级。
3. **#6 抓取、#19 监控要注意合规**：涉及外部网站抓取/监控的，务必遵守目标站点 robots 协议
   与使用条款，别做成爬虫滥用工具。

**结论**：工具类是**个人开发者最快能出活**的方向（不依赖深厚行业背景），但要在
「高省时 + 低竞争」里挑，别一头扎进通用办公红海。与方向 A（垂直岗位 SOP）的区别是：
工具类卖「操作提效」，SOP 类卖「行业判断力」——前者易起步，后者壁垒深。

### 方向 D：你本人已有领域经验的场景（⭐ 兜底，优先级由你定）

**逻辑**：最值钱的 Skill 不是程序员写的，是「行业里的人」写的。你比我更清楚自己每周
在重复做什么、哪里最痛。把那个流程写出来，就是最好的选题。

## 三、推荐开发路径

基于「能快速验证、有真实付费潜力、避免红海」三点，建议按以下顺序推进：

### 第一步：定方向（本轮就做）

- 从方向 A 里挑**一个你真正懂、且愿意持续维护**的岗位场景。
- 用一句话公式锁定选题：
  > 这个 Skill 通过【核心流程】，为【目标人群】完成【具体任务】，每周省 X 小时。
- 一句话说不清，就说明选题还没想透，别急着写。

### 第二步：产品定义（写 SKILL.md 前必须想清 6 件事）

1. **正向触发器**：5–7 个用户真实会说的触发指令；
2. **反向过滤器**：明确「哪些相似场景不该触发」，不设边界 = 乱输出；
3. **输入规范**：用户给什么（CSV？网址？原始文字？），写清楚；
4. **输出标准**：固定格式 / 结构 / 字数 / 核心模块；
5. **质量红线**：什么算好、什么算差，提前定义；
6. **边缘预案**：数据缺了怎么办、信息不全怎么处理。

### 第三步：最小可用（MVP）+ 实测

- 按仓库既有规范（见 `AGENTS.md` 第 4 节）：SKILL.md 骨架 + 一个能跑通的脚本。
- **必须真跑 10 组真实场景**，重点抓五类问题：
  沉默失效（触发词弱）→ 错误劫持（边界不严）→ 输出漂移（工作流不细）→
  AI 幻觉（缺数据规则）→ 格式混乱（模板不固定）。
- 只写实测过的参数，没跑通就留 TODO。

### 第四步：过三关 + 上架

```bash
python build/pack.py check skills/<name>   # 字段、白名单、版本一致性
python build/pack.py pack  skills/<name>   # 能出包
# author 换成真实入驻主体名（见 docs/publish.md 七步流程）
```

- 先免费攒口碑，再上付费版（一次性买断 / 订阅）做利润。
- 上架流程见 `docs/publish.md`。

### 里程碑清单

| 里程碑 | 产出 | 验收标准 |
|---|---|---|
| M1 选题锁定 | 一句话公式 + 5 个触发词 + 反向边界 | 你能一句话说清它做什么 |
| M2 产品定义 | 六件事写全 | 输入/输出/红线/边缘都有答案 |
| M3 MVP 实测 | SKILL.md + 脚本 + 10 组用例 | 连续 10 次输出稳定可用 |
| M4 上架 | 过三关 + 提交审核 | `pack.py check` 全绿 |

## 四、与现有技能的关系

- `bilingual-subtitle` 保持独立，不并入新技能；新技能要避免触发词与它重叠。
- 若新方向属于「字幕/视频」相邻场景，优先考虑**并入 bilingual-subtitle** 而非另起炉灶
  （判据见 `AGENTS.md` 第 4 节「触发条件不与其他技能重叠」）。

---

## 五、下一步需要你拍板

本轮调研的结论是：**方向已明确（做垂直岗位 SOP），但具体做哪个岗位需要你定**，因为
「你真正懂哪个行业」只有你清楚。请回答：

1. 方向 A 里你最有把握、愿意长期维护的是哪个？（教学设计 / 客户周报 / 招聘 HR / 其他）
2. 或者你更想做「方向 B 全流程升级」去切哪个相邻细分？
3. 你手头有没有「每周重复、流程固定、早就想自动化」的具体活，可以直接当选题？

定了之后，我可以立刻按第三节的路径帮你产出第一个新技能的 SKILL.md 骨架和产品定义。
